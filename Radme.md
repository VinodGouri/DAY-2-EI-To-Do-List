# To-Do List Web App

This is a simple To-Do List web app built using **HTML**, **CSS**, and **Vanilla JavaScript**.

## Features
- Add tasks using the input field and button.
- Mark tasks as complete by clicking on them.
- Delete tasks with a delete button.
- Instantly updates without page reload.

## Files
- `index.html` - Main structure of the app.
- `styles.css` - Basic styling and layout.
- `app.js` - Handles adding, completing, and deleting tasks.
- `README.md` - Project information.

## How to Run
1. Download or clone this repo.
2. Open `index.html` in a browser.
3. Type a task and click **Add**.
4. Click on the task to mark it complete, or use **Delete** to remove it.

## Learning Focus
- DOM manipulation
- Event handling
- State updates without page reload
